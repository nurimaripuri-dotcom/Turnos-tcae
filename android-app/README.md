# App Android (Capacitor)

APK que abre la web en vivo (`https://nurimaripuri-dotcom.github.io/Turnos-tcae/`).
Los cambios en `index.html` se ven en la app sin reinstalar.

- Compilación: `.github/workflows/android.yml` (se lanza al cambiar algo en `android-app/`).
- Descarga: https://github.com/nurimaripuri-dotcom/Turnos-tcae/releases/latest/download/TurnosTCE.apk
- Firma: secrets `ANDROID_KEYSTORE_*` del repo (copia de seguridad fuera de GitHub).
